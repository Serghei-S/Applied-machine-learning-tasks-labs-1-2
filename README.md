# Прикладные задачи машинного обучения - лабораторные работы 1-2

В репозитории собраны две лабораторные работы. Каждая находится в отдельной папке и содержит один выполненный Jupyter Notebook с выводами ячеек.

| Работа | Задача | Материалы |
|---|---|---|
| 1. Большие языковые модели | Проверка соответствия заявленной отрасли тексту сайта компании: пять LLM и baseline | [Описание и запуск](lab-1/README.md) · [Ноутбук](lab-1/lab1_company_activity_llm.ipynb) · [Отчёт Word](lab-1/Отчёт_ЛР1_Оценка_деятельности_организаций.docx) |
| 2. Мультимодальные модели | Прогноз направления движения акции по тексту, котировкам и графику: восемь вариантов | [Описание, результаты и запуск](lab-2/README.md) · [Ноутбук](lab-2/lab2_multimodal_stocknet.ipynb) · [Отчёт Word](lab-2/Отчёт_ЛР2_Мультимодальные_модели.docx) |

В ноутбуках сохранены метрики, время работы, примеры ответов и графики. Для нового полного запуска используется Kaggle с GPU и включённым Internet; конкретные настройки приведены в README каждой работы.

Ключи доступа и веса моделей в репозиторий не включены.

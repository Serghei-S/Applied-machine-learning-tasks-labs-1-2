# Лабораторная работа 1 - Большие языковые модели

Лабораторная работа по прикладным задачам машинного обучения.


В [ноутбуке](lab1_company_activity_llm.ipynb) сравниваются пять LLM и baseline TF-IDF + LogisticRegression. Для каждого примера модель проверяет, соответствует ли заявленная отрасль тексту сайта компании. Возможные ответы: `match`, `mismatch`, `insufficient`.

| Модель | Точность весов | Режим |
|---|---|---|
| Qwen2.5-14B-Instruct | NF4, 4 bit | zero-shot |
| Qwen3-8B | FP16 | zero-shot |
| Mistral-7B-Instruct-v0.3 | FP16 | few-shot |
| Qwen2.5-32B-Instruct | NF4, 4 bit | zero-shot |
| Phi-3.5-mini-instruct | FP16 | few-shot |

Few-shot включает три примера из train. Веса LLM не дообучаются. Основная метрика - Macro-F1; также выводятся Accuracy, F1 для `mismatch`, MCC, доля ошибок JSON, время и GPU-память.

## Данные и отдельная проверка выбранной модели

Источник - [Company classification](https://www.kaggle.com/datasets/charanpuvvala/company-classification), версия 1. Используются 100 компаний из пяти отраслей. Разбиение выполняется по компаниям до создания пар; дубликаты удаляются.

| Подвыборка | Компаний | Пар | Назначение |
|---|---:|---:|---|
| train | 40 | 90 | Обучение baseline и выбор few-shot примеров |
| validation | 10 | 25 | Выбор модели по Macro-F1 и доле ошибок JSON |
| test | 30 | 70 | Сравнение пяти конфигураций |
| application | 20 | 45 | Отдельная проверка выбранной модели |

Модель выбирается по validation, затем проверяется на application в разделе «Ошибки и применение». Компании application не используются для обучения, демонстраций или выбора победителя. Это отдельная часть того же датасета, а не внешний или более новый источник. Метки заявлений создаются программно, поэтому эксперимент остаётся пилотным.

## Запуск

1. Открыть ноутбук в Kaggle и подключить датасет `charanpuvvala/company-classification`, версия 1.
2. Включить **GPU T4 ×2** и **Internet**.
3. Выполнить **Run All**. Каждый запуск заново готовит выборку и выполняет инференс всех моделей.

Ответы и промежуточные метрики выводятся под ячейкой каждой модели. Общие таблицы и графики находятся в разделе **«8. Качество и время»**, результаты application - в разделе **«9. Ошибки и применение»**.

Ноутбук получен из [версии 7 на Kaggle](https://www.kaggle.com/code/sergheisheptichin/vkr-company-activity-fp16-fewshot-final). Код, комментарии и выводы ячеек сохранены вместе в одном `.ipynb`.

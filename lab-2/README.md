# Лабораторная работа 2 - Мультимодальные модели

**Задача:** прогноз направления движения акции в следующую торговую сессию по сообщениям о компании, прошлым котировкам и свечному графику.

- [Выполненный ноутбук](lab2_multimodal_stocknet.ipynb): код, таблицы, графики и выводы в одном файле.
- [Обзор пяти ключевых статей](Обзор_5_статей.md).
- [Kaggle, версия 4](https://www.kaggle.com/code/sergheisheptichin/lab-2-multimodal-stocknet-eight-variants).

## Данные и протокол

Используется небольшая выборка из [StockNet](https://github.com/yumoxu/stocknet-dataset): 659 объектов для восьми компаний. Один объект объединяет сообщения до закрытия торгов, 20 прошлых торговых сессий OHLCV и построенный по ним график. Цель - знак изменения скорректированной цены закрытия в следующую сессию.

| Подвыборка | Объектов | Назначение |
|---|---:|---|
| train | 400 | Обучение классификаторов |
| calibration | 48 | Калибровка вероятностей |
| validation | 64 | Выбор варианта |
| test | 120 | Итоговое сравнение |
| application | 27 | Отдельная проверка на Facebook и Oracle |

Группы разделены по времени с промежутками между окнами котировок. Facebook и Oracle исключены из обучения, калибровки и выбора. Цена и её график представляют один источник данных в разных формах. Это проверка на отдельной части StockNet, а не на внешнем наборе данных.

## Восемь вариантов сравнения

| Вариант | Состав | Режим |
|---|---|---|
| Только текст | FinBERT FP16 + Logistic Regression | Обучается классификатор |
| Только числа | Признаки котировок + Logistic Regression | Обучается классификатор |
| Только график | CLIP ViT-B/32 FP16 + Logistic Regression | Обучается классификатор |
| Early fusion: текст + числа | Объединение текстовых и числовых признаков | Обучается классификатор |
| Early fusion: все входы | FinBERT + CLIP + числовые признаки | Обучается классификатор |
| Late fusion: все входы | Среднее вероятностей трёх unimodal baseline | Отдельная калибровка |
| BLIP-2 OPT-2.7B | Визуальный энкодер + Q-Former + OPT, FP16 | zero-shot |
| Qwen2.5-VL-7B | Мультимодальная языковая модель, NF4 | zero-shot |

Веса энкодеров и языковых моделей не дообучаются. BLIP-2 и Qwen получают все три входа, оценивают ответы A/B и отдельно калибруются. В notebook также показана масса вероятности этих ответов: у BLIP-2 она низкая, поэтому условные оценки A/B не следует считать оценкой качества свободной генерации. Абляционные эксперименты не проводятся.

## Результаты на test

| Вариант | Accuracy | Macro-F1 | AUROC | Медианное время, мс |
|---|---:|---:|---:|---:|
| Только текст | 0.467 | 0.414 | 0.453 | 9.3 |
| Только числа | 0.467 | 0.444 | 0.480 | 1.0 |
| Только график | 0.458 | 0.314 | 0.507 | 217.7 |
| Early fusion: текст + числа | 0.500 | 0.422 | 0.489 | 9.1 |
| Early fusion: все входы | 0.475 | 0.348 | 0.512 | 229.3 |
| Late fusion: все входы | 0.458 | 0.314 | 0.457 | 230.1 |
| BLIP-2 OPT-2.7B | 0.475 | 0.380 | 0.443 | 494.5 |
| Qwen2.5-VL-7B | 0.458 | 0.314 | 0.510 | 1552.9 |

Для лёгких схем время оценивается как сумма отдельно измеренных этапов; для BLIP-2 и Qwen измеряется полный запрос. Для вариантов с изображением добавляется построение графика. Загрузка весов показана отдельно.

По правилу выбора на validation победил вариант **«Только числа»**. Подтверждённого прироста от объединения входов не получено. На отдельных компаниях: Accuracy = 0,481; Macro-F1 = 0,417. Результаты относятся к небольшой исторической выборке; попадание исторических событий в предобучение моделей исключить нельзя.

## Запуск

1. Открыть `lab2_multimodal_stocknet.ipynb` в Kaggle.
2. Включить **Internet** и **GPU T4**. Модели запускаются последовательно на одном GPU.
3. Выполнить **Run All**. Данные загружаются автоматически; токены API не нужны.

Все метрики, примеры ответов, время, память и графики выводятся прямо в ячейках. Дополнительные файлы сохраняются в `/kaggle/working/lab2`. Сохранённый запуск выполнил все 26 ячеек кода без ошибок.
